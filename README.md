# B12A06 Green Earth 🌳

**Live Site:** [http://lustrous-sfogliatella-3f1c41.netlify.app](http://lustrous-sfogliatella-3f1c41.netlify.app)  
**GitHub Repo:** [B12A06 Green Earth Repository](https://github.com/shanto522/B12A06-Green-Earth.git)

Green Earth is an eco-friendly digital platform where users can browse, select, and purchase trees for planting. The website makes tree buying easy and interactive, helping users contribute to reforestation and environmental sustainability. The platform provides detailed information on each tree, including type, benefits, and planting guidance, ensuring users can make informed choices. Designed with a clean interface, the site is fully responsive and provides a smooth experience across all devices.

---

## Main Features

- Browse a variety of trees with details like species, benefits, and planting info.
- Buy any tree directly from the platform.
- Interactive and user-friendly interface for smooth navigation.
- Responsive design for desktop, tablet, and mobile.
- Quick search and filtering to find the right tree.
- Detailed tree information for informed purchasing decisions.

---

## Technologies Used

- **Frontend:** React, TailwindCSS
- **UI & Icons:** React Icons
- **State Management & Data Fetching:** Custom Hooks
- **Performance Optimization:** Lazy Loading, React Suspense
- **JavaScript:** Modern ES6+ features

## Instructions to Run Locally

1. **Clone the repository**:
    ```bash
    git clone https://github.com/shanto522/B12A06-Green-Earth.git
    ```

2. **Navigate to the project directory**:
    ```bash
    cd B12A06-Green-Earth
    ```

3. **Install dependencies**:
    ```bash
    npm install
    ```

4. **Start the development server**:
    ```bash
    npm start
    ```
